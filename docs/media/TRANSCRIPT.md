# Video transcript

Silent, captioned walkthrough made from real app captures; model waits are shortened.

## 00:00 — Your model. Your project.

Open your project folder. Choose an existing model at the top and look for Connected. Cipher does not download a model.

## 00:09 — Keep the model you chose.

Settings & models opens Model connection. Local Ollama uses localhost:11434. Select your installed model, save, and check tool compatibility.

## 00:17 — See the files you work on.

Expand folders in Explorer. Click a file to open source tabs with syntax colours and line numbers. Back to chat returns to your conversation.

## 00:26 — Ask in everyday language.

Choose Ask, Plan, or Build. Here, Build asks the existing model to fix one small bug and run the tests. Enter sends. Shift+Enter adds a line.

## 00:36 — No manual file attachments.

The model reads relevant project files using tools. Activity shows which files were actually read. Long model waits are shortened in this walkthrough.

## 00:44 — Read it before you save it.

Check the filename and proposed line changes. Approve & save writes the change. Reject leaves the proposal unapplied.

## 00:55 — Review the exact command.

The model requests the Python test command for this sample. Read the command and working folder before choosing Run command.

## 01:04 — Look at the actual results.

Open Terminal to inspect the real command output. This sample passes both tests after the saved fix. Check the changed source too.

## 01:14 — The saved file is yours.

Click the changed file in Explorer. The actual source now multiplies price by quantity. You can also edit files yourself using Edit file.

## 01:21 — A little coffee. Your colours.

Coffee briefly shows a sip, returns to chat, and keeps the computer awake. Change colour changes the whole app. Turn Coffee off to restore normal idle sleep.

## 01:25 — The whole app changes.

Choose a colour dot, use Change colour to cycle forward, or use the arrow to go back. Your choice is remembered.

## 01:30 — A guide is always nearby.

Getting started reopens the built-in tour. Read the beginner guide, then try a small task in your own project. Free and open source on GitHub.
